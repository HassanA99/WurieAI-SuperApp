# WurieAI Engineering Roadmap

## Sprint 0: Product and System Foundation

- Lock the product scope and launch geography.
- Define user roles: customer, provider, driver, admin.
- Define data ownership boundaries.
- Choose service domains and response contracts.

## Sprint 1: Identity and Profile

- Firebase project setup.
- Firebase Auth configuration.
- App Check setup.
- Firestore user collection.
- Profile completion flow.

## Sprint 2: Agent and Backend API

- Cloud Run FastAPI service.
- Firebase ID token validation middleware.
- Chat endpoint with structured output.
- Agent router and domain routing rules.

## Sprint 3: Domain Services

- Market service and Firestore prices.
- Provider service and registration workflow.
- Booking and ride service skeleton.
- Wallet service skeleton.

## Sprint 4: Cross-Service UX

- Feed chat results to UI navigation.
- Provider chat flow.
- Booking tracking flow.
- Notifications and activity feed.

## Sprint 5: Security and Scale

- Firestore rules.
- Cloud Secret Manager.
- Request limits and monitoring.
- Logging and observability.

## Sprint 6: Launch and Growth

- Analytics events.
- Provider quality review.
- Admin dashboard.
- Quality checks and launch readiness.
